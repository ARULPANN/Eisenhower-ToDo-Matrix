# Eisenhower-ToDo-Matrix
Eisenhower-style Urgent/Important matrix app for Windows and Android. Drag points between four blocks, tick them off as complete, and track completion % per block. Save and load your data as JSON
A simple time-management app based on the Eisenhower matrix, with four blocks: Urgent and Important, Not Urgent and Important, Urgent and Not Important, and Not Urgent and Not Important.

Drag and drop points between blocks, or reorder them within a block
Mark a point complete to strike it through. It moves to the top of the completed points in its block
Completion % is shown for each block
Mobile layout with bottom tabs. Long-press a point and drag it onto a tab to move it to another block
Save and upload your data as a JSON file
Works offline, and your data is kept on the device
Available for Windows (Electron) and Android (Capacitor)
