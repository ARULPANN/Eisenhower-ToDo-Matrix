BUILD THE APK (no Android Studio needed)
1. Create a free account at github.com and make a NEW repository (private is fine).
2. Upload ALL files from this folder (including the hidden ".github" folder) to the repository.
3. Open the repository's "Actions" tab -> "Build Android APK" -> wait ~5 minutes for the green tick.
4. Open the finished run, download "Eisenhower-ToDo-Matrix-APK" (a zip), unzip to get app-debug.apk.
5. Copy the APK to your Android phone and open it. Allow "install unknown apps" when asked.
